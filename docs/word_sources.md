# 단어장 선정 근거와 검증 정책 (2026-10-13)

## 1. 선정 근거 (솔직한 기록)
- JLPT 공식 어휘 목록은 공개되지 않는다. 따라서 급수 배정은 **AI(Claude)의 판단**이며, 사람 검수를 거치지 않았다.
- AI 가 초안을 쓸 때 참고한 것은 특정 파일이 아니라 모델이 학습한 공개 자료의 기억이다: 구 JLPT 출제기준(2002년판) 4급·3급 어휘표에 해당하는 공개 목록, 『みんなの日本語』 초급 I·II 어휘, 널리 쓰이는 N5·N4 학습 사이트의 어휘 목록. 버전을 특정할 수 없으므로 "비공식·AI 생성"으로 표기한다.
- 급수가 엇갈릴 수 있는 단어(예: N4 에 넣은 現在·未来·過去·自然·平和·国民 은 N3 목록에 더 자주 나온다)는 실사용 뒤 조정한다. 같은 이유로 단어 데이터에 `tier`(core/ext)를 두어 "핵심 700개"와 확장을 구분한다.
- 보조 자료 후보: 국립국어연구소 BCCWJ 어휘 빈도표(문어 빈도. 급수로 바로 바꾸지 않고 선정 우선순위 보조로만). 이용 조건을 확인한 뒤 N3 부터 적용한다.

## 2. 검증 정책 (외부 검토 반영)
- 읽기 검증은 JMdict 전체(jmdict-simplified 영어판)와 대조한다. 이전(2026-10-12까지)에는 "common" 표기만 추린 판과 대조해, 자주 쓰는 단어 12개를 다른 단어로 바꾸는 잘못이 있었다. 해당 단어는 새 id 로 되살렸다(아래 표).
- 판정은 3단계: 통과 / 검토(접두 お·ご 형태, 복합어 등. 사람이 확인) / 보류(읽기가 사전과 다르거나 어디에도 없음. 출시 대상 제외). "검증할 수 없음"과 "잘못된 단어"를 구분한다. お·ご 를 자동으로 떼어 통과시키지 않는다.
- 읽기 일치 외 검수 항목(scripts/review_content.py 가 목록을 만든다): 예문에 단어 포함 여부, 뜻 중복(읽기 입력 정답 특정), 복수 읽기 한자어가 든 예문의 음성 청취, 급수 배정 근거.
